# NEET Counselling Choice Optimizer & Process Navigator

An academic full-stack web application designed to help NEET aspirants
build an optimized college choice list using historical cutoff data.

⚠️ **Project Status:** In Progress (MVP Phase)

---

## 🎯 Problem Statement

NEET counselling is confusing not because students lack information,
but because they struggle with:
- Ordering 100+ college choices strategically
- Understanding Safe / Target / Dream options
- Making confident decisions during counselling

This project focuses on **choice list optimization**, not admission prediction.

## 🧠 System Overview

1. User enters NEET rank, category, state, and preferences
2. Backend fetches historical cutoff data
3. Algorithm categorizes colleges into:
   - 🎯 Safe
   - ⚡ Target
   - 🚀 Dream
4. System suggests an optimized order and validations
5. Results are shown in an easy-to-understand UI
